# Discover Tab

A mobile-first swipe-based discovery feature built with **Next.js**, **Tailwind CSS**, **Framer Motion**, and an **Express** backend.

## Features
- **Discover Tab:** Swipe right to like or left to pass using touch/mouse drag, desktop buttons, or `←` / `→` arrow keys.
- **Privacy-First Matching:** Mutual likes trigger an *"It's a match!"* celebration screen. Unilateral likes are never revealed.
- **Matches View:** Displays all mutual matches with persistent storage (`data/db.json`).
- **30+ Seeded Profiles:** Includes pre-seeded mutual likes for instant demo testing.
